# 按证据逐层验收

## L0：文档与静态检查

检查 skill 链接、模板标记、私有信息和示例语法。可用独立 `mlint`/Code Analyzer 检查 MATLAB 源码；不因此启动主 MATLAB 或 HFSS。语法通过不证明函数行为。

## L1：离线行为

用合成曲线、临时目录和故障注入测试单位、映射、身份变化、缓存失效、重复 job、发布顺序和预算。测试输出限定在沙盒，拒绝测试也不以真实活动目录为靶子。

本仓库测试仅覆盖候选比较器；没有包含完整仿真队列、预算服务或恢复实现。不能把参考文档描述的约束当作已通过的测试。

## L2：独立 MATLAB mock

在单独会话运行解析目标，检查 options、OutputFcn、checkpoint、停止和恢复。存储路径与所有函数解析路径必须属于该 mock。一次完整运行不等于已验证中断恢复；需单独测试中断场景。

## L3：独立 HFSS 单点

在明确授权的计算预算内，使用空闲模型副本、新输出根和完整 manifest。写入变量→读回→求解→导出→验证→评分；人工或独立接口核对一个已知点。记录 solver 版本、收敛证据和导出设置。

## L4：小预算闭环与恢复

先以少量点跑完整链路，再验证请求提交后/结果发布前等关键中断点。确认没有额外求解、没有跨目录写入，且错误身份不能被接收。实际 Windows/AEDT Python 的文件行为也必须在此验证。

## L5：正式优化与精度复核

确认预算和实验定义后开始；保留有效配置、原始数据及失败记录。对候选进行更高精度复核。运行中变更目标或拓扑应创建新实验，不覆盖原记录。

报告达到的最高层与未覆盖项。若权限限制进程可见性、模型来源未认证或当前运行忙碌，明确标注，不把它们转换成“检查通过”。
