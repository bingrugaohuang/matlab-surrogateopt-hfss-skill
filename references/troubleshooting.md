# 遇到过的问题与定位方式

这些条目来自工作流审查和隔离改进经验；不是所有环境都会出现。先复现与收集证据，再改动一个具体原因。

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 续跑后预算/记录逻辑消失 | options 是否从默认重新构造；OutputFcn/CheckpointFile 是否仍在 | 加载原 options，只修改允许变更字段；独立预算保护仍需存在 |
| 改了新版函数却执行旧代码 | `which name -all`、`functions(handle).file`、当前 MATLAB 目录 | 在新会话固定入口与目录；写操作前验证 helper 来源，`addpath -begin` 不足以抵消当前目录优先级 |
| 重启后同一点重复求解 | 票据是否持久化、job 是否复用、done 是否可信 | 以规范化设计键和 job 恢复；不要只依赖内存计数 |
| 完成数少于预留数 | queued/working/prepared/done 的状态 | 未完成不等于泄漏预算；不要删除票据再补发 |
| 参数变了但曲线像旧点 | 变量读回、导出 variation、响应 job、缓存命名空间 | 核对全部实际变量和曲线身份；遇到不一致停止提交 |
| 旧点分数异常好 | 仿真设置与目标版本是否一致 | 相同仿真曲线可以重评分；来源不全的旧 Fval 只作历史参考 |
| 总分降了但图看起来更差 | 每项 RMSE、尺度、权重及贡献 | 同时报告各通道与折中候选；不要在活跃轮次悄改权重 |
| 导出了 CSV 就被标记收敛 | 自适应 pass、误差准则、最大 pass 停止原因 | exported 与 converged 分开；最终候选需要更严格精度复核 |
| 群时延尖峰/突变 | Hz/GHz、rad/deg、unwrap、深零点与插值 | 用复数 S 参数和更密/更准确频点交叉验证，不能先平滑掩盖问题 |
| 进程列表为空但可能仍在运行 | 权限、远程主机、进程可见性 | 标记 unknown；心跳旧也不能单独认定卡死 |
| 无图形启动失败 | 许可、安装路径、桌面会话、后端版本 | 保留已验证启动链，在独立空闲工程逐项验证 |
| MATLAB 结果账本重复/顺序混乱 | job/run、行号、相对时间，局部 seq 是否重置 | 按 run+job 去重，用账本顺序或时间排序 |
| 测试误写原工程 | 输出路径是否可由任意 CLI 参数逃逸 | 所有测试使用临时沙盒；明确校验解析后的输出根；不要拿活动目录测试拒绝逻辑 |
| 原子替换在 AEDT 内失败 | Python 版本、Windows 文件锁、.NET 分支 | 针对实际嵌入式运行时测试；失败不覆盖旧结果，不伪报成功 |

失败应分层：几何不可行可按预先定义的约束策略处理；短暂导出失败可有界重试；身份冲突/模型漂移直接停止提交。仅在安装版本支持且明确设计的策略中使用 NaN 标记失败，保留失败原因；不要以有限的低罚分让错误结果成为最优点。

不要通过杀掉所有 MATLAB/HFSS 进程排错。先识别所属运行、资源所有权与当前 job；未经用户授权不干扰其他优化。
